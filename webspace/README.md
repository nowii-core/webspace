# nowii-core · Portfolio

Portfolio personale di **nowii-core**, Front-End Developer specializzato in HTML, CSS e JavaScript.

## 🚀 Tecnologie utilizzate

- **HTML5** semantico e accessibile
- **CSS3** (variabili, Flexbox, Grid, animazioni, tema chiaro/scuro)
- **JavaScript** vanilla (ES6+), senza framework o dipendenze esterne
- **Intersection Observer** per animazioni allo scroll
- **LocalStorage** per il salvataggio del tema

## ✨ Funzionalità

- Tema chiaro/scuro con salvataggio della preferenza
- Animazione "macchina da scrivere" nell'hero
- Filtro progetti per categoria
- Form di contatto con validazione lato client
- Copia email negli appunti
- Scroll progress bar
- Design completamente responsive
